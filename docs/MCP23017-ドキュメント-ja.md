## 1. 概要

**MCP23017**（Microchip）は、2つの8ビットポート（GPIOA：ピン0–7、GPIOB：
ピン8–15）を持つ16ビットI2C I/Oエキスパンダーです。各ピンは方向レジスタ
IODIRで入力/出力を個別に設定でき、GPPUによる内部プルアップ（任意）と
GPIO出力ラッチによる書き込み・読み出しに対応します。

`Firmata-MCP23017`パッケージは、このエキスパンダーを`FirmataI2C`接続の
背後でラップします。方向・プルアップ・出力設定はSmalltalk側のシャドウ
バイトとして保持され、ピン単位の操作は該当ビットだけを変更した上で
ポート全体の1バイトとして書き戻されます。読み出しはレジスタベースの
I2C読み出し形式を使用するため、StandardFirmataがポート状態を変更せずに
応答します。

## 2. 技術データ

- 2つの8ビットポートに16本のI/Oピン：GPIOA（ピン0–7）、GPIOB（ピン8–15）。
- 方向はIODIRA/IODIRBで設定：ビット`0`=出力、ビット`1`=入力。
- ピンごとの内部プルアップ（約100kΩ）をGPPUA/GPPUBで有効化。
- 動作電圧：**1.8V – 5.5V**。
- sink/source電流：**ピンあたり25mA**。
- I2Cアドレス範囲：**0x20 – 0x27**（アドレスピンA0–A2の3本、すべてGND
  = 0x20）。
- 電源投入時の初期値：全ピン入力、プルアップ無効、出力ラッチは`1`を
  読み取る。
- INT出力：オープンドレイン、アクティブロー（本パッケージでは未使用）。

## 3. 配線

| MCP23017 | Arduino Uno |
| --- | --- |
| VCC | 5V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |
| A0 | GND（アドレス0x20） |
| A1 | GND（アドレス0x20） |
| A2 | GND（アドレス0x20） |
| GPA0–GPA7 | GPIOAピン |
| GPB0–GPB7 | GPIOBピン |

同じバスに2台目を追加する場合はアドレスピンを変更します（例：A0 → VCC
で0x21）。ブレイクアウトボードにプルアップが無い場合はSDA/SCLに4.7kΩの
VCC向きプルアップ抵抗を付けてください。

## 4. クラスとAPI

`FirmataMCP23017`は`FirmataI2CDevice`（パッケージ`Firmata-I2C`）を
拡張します。

- 初期化：`initializeDevice`（IODIRA/B = 0xFF と GPPUA/B = 0x00 を書き込
  む）、`registerWithFirmata`（配線の後で！）、`addressWithAddressPins:`。
- ピン操作：`setPinMode:value:`（ピン0–15、`true`=出力）、
  `digitalWritePin:value:`（出力ピン）、`digitalReadPin:`（入力ピン）、
  `setPullUpPin:value:`（内部プルアップon/off）。
- ポート操作：`writePort:value:`（GPIOAまたはGPIOBの8ピンを一括設定）、
  `readPort:`（0=GPIOA、1=GPIOB）、`startReadingPort:`（連続ポーリング）、
  `stopReading`（ストリーム停止）。
- コールバック：`handleI2CReply:data:`（受信した`I2C_REPLY`データを処理
  してポート入力値を更新）。
- アクセッサ：`inputValueForPort:`、`outputValueForPort:`、`directionA`、
  `directionB`。

`FirmataMCP23017Constants`（クラス側）はレジスタ一覧（`iodirARegister`
0x00、`iodirBRegister` 0x01、`gppuARegister` 0x0C、`gppuBRegister` 0x0D、
`gpioARegister` 0x12、`gpioBRegister` 0x13）と仕様値（`pinCount` 16、
`portPinCount` 8、`portCount` 2、`baseAddress`/`defaultAddress` 0x20、
`addressCount` 8）を持ちます。

## 5. 例

```smalltalk
| bus expander |
bus := FirmataI2C new.
bus connectOnPort: '/dev/ttyACM0' baudRate: 57600.
bus isFirmataInstalled.
bus i2cConfig.

expander := FirmataMCP23017 new.
expander firmata: bus address: FirmataMCP23017Constants defaultAddress.
expander initializeDevice.
expander registerWithFirmata.

"GPIOAのピン0を出力にしてローに保持"
expander setPinMode: 0 value: true.
expander digitalWritePin: 0 value: false.

"ピン8（GPIOB入力）に内部プルアップを設定"
expander setPinMode: 8 value: false.
expander setPullUpPin: 8 value: true.

"GPIOAの8ピンを一度に書き込む"
expander writePort: 0 value: 16r55.

"GPIOAを読み込み、個別ピンも確認"
expander readPort: 0.
expander inputValueForPort: 0.      "最後に読み取ったGPIOAバイト"
expander digitalReadPin: 1.         "ピン1がハイならtrue"

"GPIOBを連続ストリーミング"
expander startReadingPort: 1.
expander stopReading.
```

## 6. 注意事項

- **方向ビットの意味：** IODIRレジスタではビット`0`が出力、ビット`1`が
  入力を意味します。`setPinMode:value:`がこの差を隠すため、出力なら`true`、
  入力なら`false`を渡してください。
- **シャドウバイト：** `directionA/B`と出力ラッチはイメージ内にバイトと
  して保持されます。`setPinMode:`、`digitalWritePin:`、`setPullUpPin:`は
  該当ビットだけを変更してポート全体を書き戻すため、混在構成でも再読み
  出しなしに整合が保たれます。
- **ピン番号：** ピン0–7はGPIOA、ピン8–15はGPIOBにあります。プライベート
  ヘルパー`portForPin:`と`bitForPin:`がピン番号をポートとビットに変換し
  ます。
- **GPIO読み出し：** `readPort:`はレジスタベースのI2C読み出し形式
  （StandardFirmata ≥ 2.5）でGPIOA/GPIOBレジスタを読みます。入力ピンでは
  ピンレベル、出力ピンでは駆動中のラッチ値を反映します。
- **複数デバイス：** アドレスピンにより同じI2Cバスに最大8個のMCP23017を
  接続できます。チップごとに別の`FirmataMCP23017`インスタンスを登録し、
  `FirmataMCP23017 addressWithAddressPins:`でアドレスを計算してください。
- **電源：** ピンあたり25mAがチップの上限です。それ以上の負荷は外部ドラ
  イバ段やトランジスタで駆動してください。
