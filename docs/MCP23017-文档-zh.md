## 1. 概述

**MCP23017**（Microchip）是一款16位I2C I/O扩展器，具有两个8位端口：
GPIOA（引脚0–7）和GPIOB（引脚8–15）。每个引脚可分别通过方向寄存器
IODIR 配置为输入或输出，通过 GPPU 启用可选内部上拉，并通过 GPIO 输出
锁存寄存器进行写入或读取。

`Firmata-MCP23017` 包将该扩展器封装在 `FirmataI2C` 连接之后。方向和
上拉及输出设置以影子字节的形式保存在 Smalltalk 一侧，因此逐引脚操作
只修改受影响的位，然后将整个端口字节写回芯片。读取使用基于寄存器的
I2C 读取格式，由 StandardFirmata 处理，且不会改动端口状态。

## 2. 技术参数

- 两个8位端口共16个I/O引脚：GPIOA（引脚0–7）和GPIOB（引脚8–15）。
- 方向通过 IODIRA/IODIRB 设置：位 `0` 表示输出，位 `1` 表示输入。
- 通过 GPPUA/GPPUB 启用每引脚的内部上拉（约100kΩ）。
- 工作电压：**1.8 V – 5.5 V**。
- 灌/拉电流：**每引脚 25 mA**。
- I2C 地址范围：**0x20 – 0x27**（3个地址引脚 A0–A2；全部接地 = 0x20）。
- 上电默认值：全部输入，上拉禁用，输出锁存读为 `1`。
- INT 输出：开漏、低电平有效（本包未使用）。

## 3. 接线

| MCP23017 | Arduino Uno |
| --- | --- |
| VCC | 5V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |
| A0 | GND（地址0x20） |
| A1 | GND（地址0x20） |
| A2 | GND（地址0x20） |
| GPA0–GPA7 | GPIOA引脚 |
| GPB0–GPB7 | GPIOB引脚 |

要在同一总线上挂第二块扩展器，请相应设置地址引脚，例如 A0 → VCC 得到
0x21。如果板载没有上拉，请在 SDA/SCL 上接 4.7kΩ 上拉电阻至 VCC。

## 4. 类与API

`FirmataMCP23017` 继承 `FirmataI2CDevice`（包 `Firmata-I2C`）。

- 初始化：`initializeDevice`（写入 IODIRA/B = 0xFF 和 GPPUA/B = 0x00）、
  `registerWithFirmata`（接线之后！）、`addressWithAddressPins:`。
- 引脚操作：`setPinMode:value:`（引脚0–15；`true`=输出）、
  `digitalWritePin:value:`（输出引脚）、`digitalReadPin:`（输入引脚）、
  `setPullUpPin:value:`（内部上拉开/关）。
- 端口操作：`writePort:value:`（一次设置 GPIOA 或 GPIOB 的8个引脚）、
  `readPort:`（0=GPIOA，1=GPIOB）、`startReadingPort:`（连续轮询）、
  `stopReading`（停止数据流）。
- 回调：`handleI2CReply:data:`（处理收到的 `I2C_REPLY` 数据并更新端口
  输入值）。
- 访问：`inputValueForPort:`、`outputValueForPort:`、`directionA`、
  `directionB`。

`FirmataMCP23017Constants`（类侧）提供寄存器表（`iodirARegister` 0x00、
`iodirBRegister` 0x01、`gppuARegister` 0x0C、`gppuBRegister` 0x0D、
`gpioARegister` 0x12、`gpioBRegister` 0x13）和规格（`pinCount` 16、
`portPinCount` 8、`portCount` 2、`baseAddress`/`defaultAddress` 0x20、
`addressCount` 8）。

## 5. 示例

```smalltalk
| bus expander |
bus := FirmataI2C new.
bus connectOnPort: '/dev/ttyACM0' baudRate: 57600.
bus isFirmataInstalled.
bus i2cConfig.

expander := FirmataMCP23017 new.
expander firmata: bus address: FirmataMCP23017Constants defaultAddress.
expander initializeDevice.
expander registerWithFirmata.

"GPIOA 引脚0设为输出并拉低"
expander setPinMode: 0 value: true.
expander digitalWritePin: 0 value: false.

"引脚8（GPIOB输入）启用内部上拉"
expander setPinMode: 8 value: false.
expander setPullUpPin: 8 value: true.

"一次写入 GPIOA 的全部8个引脚"
expander writePort: 0 value: 16r55.

"读取 GPIOA 并查询单个引脚"
expander readPort: 0.
expander inputValueForPort: 0.      "最近读到的 GPIOA 字节"
expander digitalReadPin: 1.         "引脚1为高则 true"

"连续流读取 GPIOB"
expander startReadingPort: 1.
expander stopReading.
```

## 6. 说明

- **方向位的含义：** 在 IODIR 寄存器中，位 `0` 表示输出、位 `1` 表示
  输入。`setPinMode:value:` 隐藏了这一差异：输出传 `true`，输入传
  `false`。
- **影子字节：** `directionA/B` 和输出锁存以字节形式保存在镜像中。
  `setPinMode:`、`digitalWritePin:`、`setPullUpPin:` 只修改受影响的位并
  写回整个端口字节，因此混合配置无需重新读取芯片也能保持一致。
- **引脚编号：** 引脚0–7位于 GPIOA，引脚8–15位于 GPIOB。私有辅助方法
  `portForPin:` 和 `bitForPin:` 负责将引脚号映射到端口和位。
- **GPIO 读取：** `readPort:` 通过基于寄存器的 I2C 读取格式
  （StandardFirmata ≥ 2.5）读取 GPIOA/GPIOB 寄存器，不会改动端口状态。
  输入引脚反映引脚电平，输出引脚反映被驱动的锁存值。
- **多设备：** 通过地址引脚可在同一 I2C 总线上挂最多8个 MCP23017。为
  每块芯片注册一个独立的 `FirmataMCP23017` 实例，并用
  `FirmataMCP23017 addressWithAddressPins:` 计算地址。
- **供电：** 每引脚25mA 是芯片上限；更大负载需通过外置驱动级或晶体管
  驱动。
